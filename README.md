# Importaciones VOLF

App web de COMEX: estado de cada operación (🏭 fábrica, 🚢 en agua, VOLF), fecha de llegada y packing list.

- Dirección: https://volf2026.github.io/volf-comex/
- Vendedores: abrir la dirección en Chrome, ingresar la clave de acceso y, en el celular, elegir "Instalar" o "Agregar a la pantalla de inicio".
- Los datos están cifrados en `datos.enc.json`: sin la clave de acceso no se pueden leer.
- Se actualiza sola desde la PC de VOLF con el programa COMEX_APP (planilla de operaciones y packing lists). No se publican montos, precios ni observaciones.
